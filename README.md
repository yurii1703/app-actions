# Ритм

Невеликий сервіс персональних списків завдань. Кожен користувач має власний список; головна показує команду, загальну статистику та трьох користувачів із найвищим відсотком виконання.

## Запуск

```sh
npm install
npm run dev
```

Vite доступний на `http://localhost:5173`, а API працює на `http://localhost:4173`. Дані зберігаються у `data/users.json` і залишаються локальними.

Для production спочатку зберіть клієнт, потім запустіть Node-сервер:

```sh
npm run build
npm start
```

Сервер обслуговує зібраний застосунок та API на порту `4173`. Порт і шлях до файлу БД можна змінити змінними `PORT` і `DATABASE_FILE`.

## Тести

```sh
npx playwright install chromium
npm test
```

`npm run test:components` запускає компонентні тести Playwright; `npm run test:e2e` перевіряє браузерний сценарій і збереження даних у тестовій JSON-БД.
